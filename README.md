## Deskripsi Singkat
Proyek ini berisi *scene* 3D interaktif yang dibangun menggunakan A-Frame untuk memenuhi tugas praktikum perkenalan diri.

## Rincian Elemen Scene
1. **Objek Primitif 3D:**
   - `a-box` (Kotak) berwarna biru.
   - `a-sphere` (Bola) berwarna merah.
   - `a-cylinder` (Silinder) berwarna kuning.
2. **Lingkungan & Warna:**
   - `a-sky` (Langit) berwarna Biru Cerah (`#87CEEB`).
   - `a-plane` (Lantai) berwarna Abu-Abu Gelap (`#334155`).
3. **Identitas Diri:**
   - `a-text` menampilkan teks Nama dan NIM di atas objek 3D.
4. **Animasi:**
   - Atribut `animation` dipasang pada objek `a-cylinder` sehingga berputar 360 derajat secara kontinu (*looping*).
